# Cake Galaxy – production OTP by MSG91 SMS

As of October 23, 2026 the owner received a MSG91/Meta error while trying to create a WhatsApp Business authentication template: “This WhatsApp Business Account does not have permission to create message template.” The application cannot bypass provider permissions.

The server now supports **MSG91 SendOTP + Verify OTP** by SMS as the first choice whenever `MSG91_SMS_OTP_TEMPLATE_ID` is configured. The API selects WhatsApp only if the SMS template ID is absent. Production OTP codes are generated by MSG91, not Cake Galaxy, and verified with MSG91. This route has the existing per-phone 30-second cooldown, 5 requests per 15 minutes, per-IP rate limits, 5 verification attempts, and 5-minute challenge expiry. Never expose the MSG91 auth key to browser code or logs.

Before live SMS can work, complete and verify (1) MSG91 balance/service active, (2) India DLT entity registration, (3) approved sender/header and approved OTP message content on DLT, (4) map the DLT approval in MSG91 OTP templates, and (5) copy the **MSG91 OTP template ID** (NOT WhatsApp template name, NOT DLT content ID) into Render backend environment variable `MSG91_SMS_OTP_TEMPLATE_ID`. Use existing backend secret `MSG91_AUTH_KEY`; do not put it in frontend environment variables. Trigger a deploy after changing env vars. Test with a consenting live Indian phone and enter the actually received 6-digit SMS code; inspect provider logs if SMS does not arrive.

MSG91 send: POST https://control.msg91.com/api/v5/otp?template_id=...&mobile=91...&otp_length=6&otp_expiry=5 with `authkey` server header; verify: GET /api/v5/otp/verify?mobile=91...&otp=... . Do not imply that a successful provider API acknowledgement guarantees mobile delivery. Docs: https://docs.msg91.com/otp/sendotp and https://docs.msg91.com/otp/verify-otp .

If MSG91 SMS template is not approved/configured, the backend does NOT fabricate success or enable unrestricted test codes; live OTP remains unavailable until provider setup is completed.
