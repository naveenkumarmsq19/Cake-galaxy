# Cake Galaxy Checkout – October 23, 2026

- Removed standalone "Test siren" from Admin without changing the emergency-style alert, repeating interval, Mute, volume slider, or click-to-enable requirement.
- Cart and Delivery Details forms now restrict delivery dates to today–31 calendar days (IST). After the last slot starts, today's date disappears. Time options dynamically filter out already-started slots; controls update every 30 seconds. Changing the date clears the selected slot. Checkout validates again immediately before order submission, and the backend always checks deliveryDate + validateDeliverySlot against the live IST clock.
- Address form has an optional map pin picker that loads Leaflet 1.9.4 on demand with pinned CDN integrity hashes. Interactive OSM tiles allow tap-to-drop, drag-to-adjust and an explicit GPS permission request. The pin coordinates are stored with the order if chosen; existing street, landmark, city, pincode, and eligible delivery service area checks remain mandatory and unchanged. When map assets cannot load the manual address form still works.
- Order review and Admin Orders show View pinned location links if a pin exists. Coordinates are checked on server for finite numeric coordinates in India, no automatic street-to-pin/address reverse geocoding is claimed, and pin coordinates do NOT substitute for pincode eligibility.
- The map is client-side and mobile responsive. OpenStreetMap tile service is best-effort: production growth may warrant switching to a contracted map/tile provider. Attribution is always displayed.
